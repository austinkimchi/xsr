# Benchmark results

The two published run folders contain the saturation and fixed-rate data used
by `wrk_benchmark_analysis.ipynb`. Each folder includes its run settings,
summary, policy copy, and one `result.json` per trial.

Large command output, warm-up logs, and chart exports stay local. Set
`CREATE_ARTIFACTS = True` at the top of the notebook only when local PNG, PDF,
or CSV copies are wanted.
